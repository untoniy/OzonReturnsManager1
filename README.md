# Менеджер возвратов Ozon

Приложение Windows Forms для управления возвратами и вывозами со склада Ozon.

## Требования

- .NET Framework 4.8
- Visual Studio 2019/2022 (для сборки)

## Установка токена авторизации

1. Создайте файл `token.txt` в папке проекта (рядом с `.sln` файлом)
2. Поместите в него строку токена авторизации (без кавычек и дополнительных символов)
3. Файл автоматически добавлен в `.gitignore` и не попадёт в репозиторий

Пример содержимого `token.txt`:
```
your-secure-token-here
```

## Сборка проекта

### В Visual Studio:
1. Откройте `OzonReturnsManager1.sln`
2. Установите NuGet пакет Newtonsoft.Json (автоматически при сборке)
3. Сборка → Сборка решения (Ctrl+Shift+B)

### Через командную строку (MSBuild):
```bash
msbuild OzonReturnsManager1.sln /p:Configuration=Release
```

## Запуск приложения

После сборки исполняемый файл находится в:
- `bin\Debug\OzonReturnsManager1.exe` - отладочная версия
- `bin\Release\OzonReturnsManager1.exe` - релизная версия

**Важно:** Скопируйте `token.txt` в папку с exe-файлом перед запуском.

## Интерфейс приложения

### Элементы управления:

1. **Дата с:** Выбор начальной даты периода
2. **Дата по:** Выбор конечной даты периода  
3. **Статус:** Фильтр по статусу возврата:
   - Все
   - НОВЫЙ
   - ОПРИХОДОВАН
   - ОТКРЫТ СПОР
   - 1c ОПРИХОДОВАН
   - СПИСАН
4. **Тип организац.:** Фильтр по типу организации:
   - Все
   - Процесс-Лайн (org_type = 0)
   - Время (org_type = 1)
5. **Запросить:** Кнопка загрузки данных

### Таблица результатов:

| Колонка | Описание |
|---------|----------|
| ID | Внутренний идентификатор записи |
| Дата | Дата изменения (change_moment для возвратов, return_completion_at для вывоза) |
| Тип | "Возврат" или "Вывоз" |
| Магазин | Название магазина (shop_name) |
| Offer ID | Идентификатор товара (offer_id) |

## API эндпоинты

Приложение работает с двумя эндпоинтами:

1. **Возвраты от покупателей:** `POST /api/arm/returns/getV2`
2. **Вывоз со склада Озон:** `POST /api/arm/from_stock/getRecords`

```csharp
NEW = 'НОВЫЙ'

DISPUTE = 'ОТКРЫТ СПОР'
C1ACCEPTED = '1c ОПРИХОДОВАН'
WRITTENOFF = 'СПИСАН'
```

## Примечания

- Для вывоза со склада всегда используется фильтр `return_state = "Завершено"`
- Данные сортируются по дате (новые сверху)
- При ошибке загрузки отображается диалоговое окно с сообщением об ошибке
